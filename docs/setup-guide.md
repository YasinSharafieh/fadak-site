# راهنمای قدم‌به‌قدم — ساخت اکانت‌ها و دیپلوی فدک

> هیچ کدی لازم نیست بزنی. فقط این ۳ اکانت رایگان رو بساز و بگو «انجام شد».

## گام ۱: ساخت اکانت GitHub (۵ دقیقه)
1. برو به https://github.com/signup
2. ایمیل و رمز انتخاب کن، یوزرنیم مثل `fadak-site` یا `fadakmedia` بذار
3. ایمیل رو تایید کن
4. تمام. (لازم نیست چیزی بلد باشی)

## گام ۲: ساخت اکانت Vercel (۳ دقیقه)
1. برو به https://vercel.com/signup
2. با همون ایمیل GitHub گزینه **Continue with GitHub** رو بزن
3. دسترسی به GitHub رو تایید کن
4. تمام. سایت بعداً خودکار از GitHub دیپلوی می‌شه.

## گام ۳: ساخت پروژه Supabase (۵ دقیقه)
1. برو به https://supabase.com/dashboard/signup
2. با GitHub وارد شو
3. دکمه **New project** → نام: `fadak` → رمز دیتابیس قوی انتخاب کن (یادداشت کن) → Region: نزدیک‌ترین (مثلاً Frankfurt یا Istanbul) → Create
4. صبر کن ۲ دقیقه تا ساخته بشه
5. از منوی چپ: **SQL Editor** → فایل `supabase/schema.sql` رو کپی و Run کن (من آماده‌اش کردم)
6. از **Settings → API** کلیدهای `anon` و `service_role` و آدرس پروژه رو کپی کن — این‌ها رو به من نده، خودت تو Vercel وارد می‌کنی (مرحله بعد)

## گام ۴: اتصال دامنه fadak.me به Vercel (۱۰ دقیقه)
1. تو Vercel: پروژه fadak رو باز کن → **Settings → Domains** → Add `fadak.me` و `www.fadak.me`
2. Vercel دو رکورد DNS می‌ده (CNAME / A). برو به جایی که دامنه رو خریدی (مثلاً ایرنیک / رجیسترار) و اون رکوردها رو اضافه کن.
3. ۱۰ دقیقه صبر کن تا سبز بشه. اگر گیر کردی اسکرین‌شات بفرست، راهنماییت می‌کنم.

## گام ۵: پوش کردن کد روی GitHub (من انجام می‌دم)
وقتی گام ۱ رو انجام دادی، فقط بگو «GitHub ساختم» — من دستور دقیق push رو می‌دم و تو فقط یک کلیک می‌کنی. بعد Vercel خودکار سایت رو بالا میاره.

## چک‌لیست بعد از ساخت اکانت‌ها
- [ ] GitHub ساخته شد
- [ ] Vercel با GitHub وصل شد
- [ ] Supabase پروژه fadak ساخته شد + schema اجرا شد
- [ ] دامنه fadak.me به Vercel وصل شد

وقتی هر ۴ تا رو تیک زدی، بگو «همه انجام شد» تا فاز دیتابیس و پنل مدیریت رو وصل کنیم.
