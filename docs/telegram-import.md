# ورود آرشیو از تلگرام — قانون دائمی

وضعیت: **متوقف** تا وقتی کاربر بگوید خطای my.telegram.org (`Too many attempts`) رفع شده. تا آن وقت api_id گرفته نمی‌شود، لاگین انجام نمی‌شود و هیچ کانالی خوانده نمی‌شود. بعد از رفع خطا، ادامه همان برنامه است: فقط کانال‌هایی که کاربر نام می‌برد، عکس و صوت یک مراسم، ویدیو فقط امبد آپارات، اول dry-run، و مراسم‌های ۱۴ مهر و ۲۱ مهر و ۱۲ آبان دوباره ساخته نمی‌شوند مگر کاربر بخواهد.

این روش برای مراسم، عکس، صوت و بعداً ریلز است. پلیر ویدیو، اسکرول بالای صفحه، تم، و ترتیب نماهنگ‌ها را عوض نمی‌کند.

## چرا بات فعلی کافی نیست
- `@fadak_media_bot` فقط پست‌های جدید را می‌بیند. تاریخچه کانال را نمی‌تواند بگردد.
- دانلود بات حداکثر ۲۰ مگابایت است. صوت مراسم اغلب بزرگ‌تر است.
- بات برای دستورات سایت (`/next` و بقیه) می‌ماند. آرشیو گذشته با ابزار جدا خوانده می‌شود.

## ابزار درست
اکانت تلگرام (نه بات) از طریق `tools/fadak_import`. فقط کانالی را می‌خواند که صریحاً گفته شده. چت خصوصی خوانده نمی‌شود.

نشست تلگرام، `api_hash` و کلید سوپابیس هرگز وارد گیت نمی‌شوند.

## دستور کار برای هر مراسم — یکی‌یکی
1. جستجو در کانال مشخص‌شده. متن اعلامیه: فقط خط عنوان (📌)، سخنران، مداحان. توضیح کوتاه.
2. صوت‌های همان مراسم با زیرنویس یک‌خطی (بخش قبل از «مجلس» / تاریخ / هشتگ). مثال: `شور | یوحنا`. عکس فقط از آلبوم گزارش تصویری همان مراسم است. نماهنگ، پیام تقدیر، تسلیت و پوستر جدا وارد مراسم نمی‌شود. زیر عکس هم نوشتهٔ «عکس مراسم» گذاشته نمی‌شود.
3. ویدیوی تلگرام آپلود نمی‌شود. برای هر صوت، ویدیوی متناظر از آپارات `fadakinfo` با همان عنوان، امبد داخل سایت (`videohash/vt/frame`) و همان قوانین `docs/aparat-embed-technique.md`.
4. اگر تعداد صوت‌ها N باشد، ویدیوهای مراسم هم باید دقیقاً N تا و همنام باشند. اگر معادل آپارات نبود، ویدیوی جعلی ساخته نمی‌شود؛ در گزارش می‌ماند.
5. هر مراسم صفحه خودش را در `/archive/[slug]` دارد. اسلاگ همیشه انگلیسی است، مثل `majles-12-aban`. اسلاگ فارسی صفحه را خالی می‌کند و ساخته نمی‌شود. مراسم تکراری ساخته نمی‌شود (تطبیق با `date_fa`).
6. مراسم تمام شود، بعد سراغ بعدی. ۱۴ مهر و ۲۱ مهر را دوباره نساز مگر کاربر بخواهد.

## سقف حجم — راستش
- تلگرام، از سمت اکانت، فایل را تا سقف خود تلگرام (حدود ۲ گیگ، پریمیوم ۴ گیگ) می‌دهد. محدودیت ۲۰ مگ بات اینجا نیست.
- سوپابیس رایگان هر فایل را عملاً تا حدود ۵۰ مگ می‌پذیرد و کل فضا ۱ گیگ است. باکت‌های فعلی محدودیت اضافه ندارند، ولی پلن این سقف را دارد.
- صوت بزرگ‌تر از این سقف آپلود نمی‌شود و مراسم نصفه و بی‌صدا ساخته نمی‌شود؛ در گزارش `too-large` می‌ماند.
- برای «بدون محدودیت عملی» باید فایل‌ها روی Cloudflare R2 بروند (رایگان، ۱۰ گیگ، بدون هزینه ترافیک). تا آن روز، عکس و صوت زیر سقف مستقیم به سوپابیس می‌روند.

## اجرا
فقط دستیار اجرا می‌کند. کاربر کد ران نمی‌کند.

```
python -m tools.fadak_import search --channel CHANNEL --query "۱۲ آبان"
python -m tools.fadak_import ceremony --channel CHANNEL --date "۱۲ آبان"
python -m tools.fadak_import ceremony --channel CHANNEL --date "۱۲ آبان" --commit
```

بدون `--commit` فقط گزارش است و سایت عوض نمی‌شود.
